# Osteza — WordPress

Локальний запуск:

```sh
docker compose up -d
```

Відкрий http://localhost:8080. Для наявного сайту використовуй поточний Docker volume або віднови резервну копію бази й uploads. Майстер встановлення потрібен лише для нової порожньої інсталяції.

Файли сайту знаходяться в цій папці. MySQL зберігає дані в Docker volume `db_data`. Паролі локальної БД знаходяться у `.env`, який виключено з Git. `wp-config.php` створюється контейнером під час першого запуску.

Зупинка без видалення бази:

```sh
docker compose stop
```

Порт можна змінити через `WP_PORT` у `.env`.

Поточний сайт уже налаштований у локальній базі Docker: файлів репозиторію недостатньо для його відтворення. Перед перенесенням потрібні БД, `wp-content/uploads/` і конфігурація середовища.

Стан підготовки, виконані перевірки та інструкції резервування: [docs/launch-readiness.md](docs/launch-readiness.md).

Аудит безпеки й перевірені обмеження: [docs/security-audit.md](docs/security-audit.md).
