# Виправлення після зовнішнього огляду — 28.10.2026

Обсяг: локальний WordPress на localhost:8080. Hostinger, Cloudflare та GitHub не змінювалися. Зовнішній звіт стосується іншого hostname, тому його висновки не вважаються підтвердженими для локальної копії без перевірки.

## Виправлено

- Демонстраційні відгуки приховані від публічних відвідувачів у всіх мовах. Збережені блоки не видаляються; приклади доступні лише адміністратору в режимі preview (`blocks/review-examples.php`).
- Прямі WhatsApp-кнопки в хедері, hero, сервісах, зонах, CTA, плаваючій кнопці та мобільній панелі використовують налаштований `wa.me`, а не якір контактної форми. Основні кнопки запиту кошторису залишаються посиланнями на форму.
- Email локального WordPress змінений на підтверджений користувачем `osteza.es@gmail.com`. Це налаштування БД (`theme_mods_osteza`), а не hardcoded адреса в темі. Перевірено в усіх п'яти головних сторінках; його також використовують контактні блоки й повідомлення про дані.
- Усі контактні форми використовують повний перекладений каталог послуг, включно з наявною послугою «Gestión integral de trabajos», замість лише послуг головної сторінки. 24 послуги + «Інша робота» + початковий порожній варіант. Окремий дубль управління проєктами не додавався.
- Порожнє портфоліо приховане з навігації, футера та блоків послуг/зон, доки немає реальних опублікованих проєктів відповідною мовою. Чернетки й зразки не вважаються реальними проєктами. Прямий маршрут архіву доступний і лишається noindex; прибрано текст про майбутні роботи.
- Автоматичний title сторінок зон використовує фактичний H1 з блоку zone-hero; виправлено розбіжність Calpe. Явні редакторські SEO override залишають пріоритет.
- Прибрано зайве «de» перед назвами послуг у прихованому тексті посилань карток.

## Перевірені, але не відтворені локально твердження звіту

- ES, EN, UK, RU, PL: HTTP 200, непорожні title, відповідні OG locale. Локально по 53 опубліковані сторінки/статті кожною мовою. SERVER_ERROR зовнішнього інструмента сам по собі не доводить помилку WordPress; на хостингу потрібна окрема перевірка.
- Локальна назва сайту вже OSTEZA; og:site_name та OG alt не беруть назву тимчасового хостингу.
- Блог віддає дев'ять карток, окрему featured-статтю й пагінацію в HTML. JS-підвантаження для їх появи не потрібне. Дефект «лише одна стаття» локально не відтворено.
- Порожній alt у декоративного фону, логотипного знака або дублювальної ілюстрації не замінювався вигаданим описом. Змістовним фото потрібні фактичні описи в медіатеці.
- Короткі назви сценаріїв на головній не прирівнювалися автоматично до помилкових назв сторінок; основне меню послуг генерується з назв сторінок.

## Потребує рішення перед публічним запуском

- Телефон і WhatsApp можуть бути різними навмисно. Основний номер не підтверджений; цифри не змінено.
- Гарантія 12 місяців та інші комерційні обіцянки потребують підтвердження власника; нових умов не вигадано.
- Юридичні сторінки не публікувалися з непідтвердженими даними. Потрібні погоджені тексти/реквізити та перевірка всіх мовних посилань. Наявний механізм футера показує опубліковані юридичні сторінки.
- `blog_public=0` залишено для локального/staging середовища. Відкриття індексації — окрема дія після готовності остаточного домену, HTTPS, контенту та юридичних матеріалів.
- Зовнішній Hostinger-сайт не оновлений. Попередні міграційні ZIP та SQL залишені незмінними й не містять цих виправлень/нового email; перед міграцією потрібні свіжий пакет та резервна копія актуальної БД.
